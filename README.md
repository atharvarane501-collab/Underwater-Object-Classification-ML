# 🌊 Underwater Object Classification Using Machine Learning

## 📌 Project Overview

Underwater Object Classification is a Machine Learning project developed to classify underwater sonar signals into different object categories. The project focuses on identifying whether a detected underwater object is a **Mine** or a **Rock/Normal object** based on sonar signal data.

The project uses a dataset containing sonar signal measurements. Machine Learning techniques are applied to preprocess the data, train the classification model, and predict the category of an underwater object.

## 🎯 Objectives

* Classify underwater objects using sonar signal data.
* Apply Machine Learning to a real-world classification problem.
* Perform data preprocessing and analysis.
* Train and evaluate a Logistic Regression model.
* Develop a system that can predict the category of a new sonar signal.

## 🧠 Machine Learning Algorithm

### Logistic Regression

Logistic Regression is used as the primary classification algorithm. The model learns patterns from the sonar features and predicts the class of an underwater object.

The classification output represents two categories:

* **M — Mine**
* **R — Rock / Normal Object**
